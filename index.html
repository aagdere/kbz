Kibitz

Run coding agents on your repositories from your Mac and iPhone.

Install

On a Mac, or on Debian, Ubuntu and Raspberry Pi OS:

curl -fsSL https://aagdere.github.io/kbz/install | sh

On a Mac it installs the Kibitz app, which sets up the rest when it first opens. On Linux it installs the kbz package; then choose what the machine does with sudo kbz setup.

The apt repository's key is kibitz-archive-keyring.gpg; its index is under dists/stable.
