Kibitz apt repository

Kibitz for Debian, Ubuntu and Raspberry Pi OS (amd64 and arm64). Add this repository and its signing key once, then install:

curl -fsSL https://aagdere.github.io/kbz/install.sh | sudo sh
sudo apt install kbz
sudo kbz setup

The key is kibitz-archive-keyring.gpg; the index is under dists/stable.
